The May 2026 release of OpenAI's Realtime API introduced three advanced models: `gpt-realtime-2` (flagship voice, featuring GPT-5-class reasoning and a tunable reasoning-effort knob), `gpt-realtime-translate` (live speech-to-speech translation for 70+ languages), and `gpt-realtime-whisper` (streaming speech-to-text with controllable latency and quality). For developers already using the GA Realtime API, migration is minimal—typically just updating the model ID and, optionally, configuring reasoning effort. However, teams on deprecated beta surfaces or legacy models face a substantial migration, requiring changes to endpoints, session structure, audio config nesting, and event naming. The API architecture and session lifecycles remain unchanged, with distinct endpoints for translation and transcription workloads. Pricing is consistent or reduced versus prior models, and each new model is purpose-fit: use `gpt-realtime-2` for voice agents, `gpt-realtime-translate` for dedicated translation, and `gpt-realtime-whisper` for transcription-only scenarios.
